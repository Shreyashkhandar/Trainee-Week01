# Day 2 – Python Fundamentals and Application Development

## Project Overview

Day 2 focuses on learning Python fundamentals, Object-Oriented Programming, file handling, exception handling, virtual environments, and basic data processing.

The practical work includes a Python Employee Management System and a CSV Analysis application.

## Problem Statement

Build Python programs that demonstrate fundamental programming concepts and develop applications for managing employee data and analyzing CSV records.

## Topics Covered

- Python syntax
- Variables and data types
- Lists, tuples, sets, and dictionaries
- Conditional statements
- For and while loops
- Functions
- File handling
- Exception handling
- Classes and objects
- Inheritance
- Lambda functions
- List processing
- Virtual environments
- pip and Python packages
- JSON and CSV data handling
