# Facility Inspection Dashboard

This Angular 18 standalone application is the Day 9 training dashboard. It expects the local mock API to be running at `http://localhost:3000/api`.

Start the API from the workspace root with `node day-09/api-integration/server.js`. Then run `npm start` from this folder and open `http://localhost:4200/`.

Run `npm run build` for a production build or `npm test -- --watch=false --browsers=ChromeHeadless` for the `FacilityService` Jasmine tests. See the [Day 9 project README](../README.md) for architecture and implementation notes.
