# Day 3 - Data Analysis and Visualization

## Project Overview

This project focuses on inspecting, cleaning, analyzing, and visualizing a facility hygiene dataset using Python.

## Problem Statement

Analyze facility hygiene data to identify data quality issues, calculate useful statistics, discover patterns, and create meaningful visualizations.

## Features

- NumPy array operations
- Pandas DataFrame analysis
- Excel dataset loading
- Missing value detection
- Duplicate detection
- Invalid value checking
- Outlier detection
- Data cleaning
- Statistical analysis
- Data filtering
- Grouping and aggregation
- Data transformation
- Data visualization
- Insight generation

## Dataset

The dataset contains 1000 facility records with 12 columns:

- facility_id
- location
- facility_type
- cleanliness_score
- odor_score
- waste_level
- water_availability
- footfall
- complaints
- inspection_date
- hours_since_cleaning
- hygiene_risk

After cleaning, 985 records remained.

## Technology Stack

- Python
- NumPy
- Pandas
- Matplotlib
- OpenPyXL
- Excel
