# Day 1 - Programming Fundamentals and Git

## Overview

This is my Day 1 work for the Intern Technical Training Program.

The main focus of Day 1 was to practice programming fundamentals, problem solving, data structures, basic OOP concepts, and Git/GitHub.

I completed 15 programming exercises in Java and also started an Employee Management CLI application.

## Programming Language

- Java

## Programming Exercises

I completed the following 15 problems:

1. Reverse a String
2. Check Palindrome
3. Find Largest Number
4. Find Second Largest Number
5. Remove Duplicates
6. Find Missing Number
7. Character Frequency
8. First Non-Repeating Character
9. Merge Sorted Arrays
10. Find Common Elements
11. Stack Implementation
12. Queue Implementation
13. Maximum Subarray Sum
14. Sorting Without Built-in Function
15. Find Duplicate Number

All exercises are available inside the `exercises` folder.

## Employee Management CLI

The Employee Management CLI is the practical assignment for Day 1.

The application is designed to manage employee information through a command-line interface.

### Features

The application includes the following operations:

- Add Employee
- Update Employee
- Delete Employee
- Search Employee
- List Employees
- Find Highest Salary
- Calculate Average Salary
- Filter Employees by Department
- Exit

The project is available inside the `employee-management` folder.
